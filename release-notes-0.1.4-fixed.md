## Исправленный prerelease 0.1.4

Этот файл заменяет ранее загруженный APK `0.1.4`, в котором ошибочно была встроена админ-панель. Пользовательское приложение OrvexaAuth теперь не содержит экранов, моделей, Retrofit-маршрутов или временных токенов администрирования.

### Исправления и улучшения

- Сессия не очищается при временной сетевой ошибке; ранее использованные аккаунты сохраняются без паролей.
- Credential Manager получает активный Android-экран для системного диалога сохранения пароля.
- При открытии Dashboard приложение проверяет новую версию и предлагает обновление; во время загрузки видны проценты и объём в МБ.
- Доступны польский, немецкий и испанский языки; язык выбирается из списка.
- Администрирование будет выпускаться только как отдельное приложение, а не как часть OrvexaAuth.

### Проверка APK

- Package: `com.orvexa.auth`
- Version: `0.1.4` (`versionCode 6`)
- Подписано постоянным сертификатом OrvexaAuth (RSA 4096, APK Signature Scheme v2).

> Важно: Android не может обновить уже установленную ошибочную сборку 0.1.4 другим APK с тем же `versionCode`. Если была установлена предыдущая 0.1.4, удалите её и установите этот исправленный APK. При обновлении с 0.1.3 обычная установка поверх приложения сохраняет связь с подписью.
