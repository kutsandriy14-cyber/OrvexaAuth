# ☁️ Руководство по развертыванию NetAuth в Cloudflare Workers

Развертывание на **Cloudflare Workers** — это лучший, самый надежный и абсолютно бесплатный способ разместить вашу базу данных NetAuth. 

### Преимущества Cloudflare Workers:
1. **Работает 24/7 без сна** — вам не нужно держать включенным компьютер, Termux или телефон.
2. **Бесплатный тариф (Free Tier)** — до 100 000 запросов к базе данных и KV-хранилищу в день абсолютно бесплатно.
3. **Безопасность и скорость** — сервер находится в облаке Cloudflare и работает мгновенно в любой точке мира.
4. **Не нужен ngrok** — вы получаете постоянную публичную HTTPS-ссылку вида `https://ваше-имя.workers.dev/`, которую можно сразу указать в настройках Android-приложения.

---

## 🛠 Пошаговая инструкция по настройке через браузер

### Шаг 1. Создание KV-хранилища (Базы данных)
1. В левой панели вашего аккаунта Cloudflare перейдите в раздел **Storage & databases** -> **Workers KV**.
2. Нажмите кнопку **Create namespace** (Создать пространство имен).
3. В поле **Namespace Name** введите строго: `NETAUTH_KV`
4. Нажмите кнопку **Add**. Всё, ваша облачная база данных готова к работе!

### Шаг 2. Создание Worker-скрипта (Сервера)
1. В левой панели Cloudflare перейдите в раздел **Compute** -> **Workers & Pages**.
2. Нажмите синюю кнопку **Create** (или **Create application**), затем выберите вкладку **Workers** и нажмите **Create Worker**.
3. Укажите любое имя для вашего воркера (например, `netauth-server`), и нажмите кнопку **Deploy** (Развернуть шаблон по умолчанию).
4. После успешного развертывания нажмите кнопку **Edit Code** (Редактировать код) в правом верхнем углу.

### Шаг 3. Вставка кода сервера
1. Скопируйте весь код из созданного нами файла `/termux-server/cloudflare_worker.js`.
2. В редакторе Cloudflare удалите весь стандартный код и вставьте скопированный.
3. **(Опционально)** На строке `const SERVICE_KEY = "my_secure_secret_key";` вы можете изменить `"my_secure_secret_key"` на любой ваш собственный сервисный ключ (пароль к базе). Если вы хотите отключить проверку ключа, напишите `const SERVICE_KEY = "none";`.
4. Нажмите кнопку **Save and deploy** в правом верхнем углу.

### Шаг 4. Связывание Сервера с Базой данных (Binding)
Это критический шаг, чтобы сервер Worker мог записывать данные в KV-базу:
1. Вернитесь из редактора кода на главную страницу настроек вашего воркера (`netauth-server`).
2. Перейдите на вкладку **Settings** (Настройки).
3. В левом меню настроек воркера выберите пункт **Bindings** (или **Variables & Bindings**).
4. Прокрутите страницу вниз до раздела **KV Namespace Bindings** и нажмите кнопку **Add** (или **Add binding**).
5. Заполните поля:
   - **Variable name** (Имя переменной): `NETAUTH_KV` (обязательно заглавными буквами!)
   - **KV namespace**: Выберите из выпадающего списка созданную на Шаге 1 базу `NETAUTH_KV`.
6. Нажмите кнопку **Save** (Сохранить), а затем **Deploy** (или **Deploy changes**), чтобы применить связывание.

## 📲 Подключение в Android-приложении

1. На главном экране вашего воркера в Cloudflare скопируйте его адрес (**Route**), например:
   `https://netauth-server.bot724524.workers.dev/`
2. Откройте приложение **NetAuth** на Android.
3. Перейдите в **Settings** (Настройки).
4. Укажите скопированную ссылку в поле **Server URL** (Обязательно добавьте `/` в конце).
5. В поле **Service Key** укажите ваш секретный ключ (по умолчанию в коде прописан `my_secure_secret_key`).
6. Включите **Remote Connection Mode**.
7. Теперь нажмите кнопку **Check Status** (Проверить статус). Вы увидите зеленую плашку:
   > `HTTP 200: NetAuth Cloudflare Server Active (DB: default)`

Поздравляем! Ваша облачная база данных NetAuth успешно настроена и теперь работает в облаке Cloudflare абсолютно автономно! 🚀
